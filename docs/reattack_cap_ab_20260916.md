# 单开关 A/B：补射上限 `REATTACK_MAX_SHOTS_PER_TARGET` 0 → 2

## 改动

在 `AIStrategy乐迪plus.py` 里新加一个开关，默认关闭；A/B 只翻转它：

```python
REATTACK_MAX_SHOTS_PER_TARGET = 0   # 对照（= 今天 13:45 那批）
REATTACK_MAX_SHOTS_PER_TARGET = 2   # 处理（= 今天 14:29 那批）
```

实现只有 3 处插入（见 `AIStrategy_cap2.py` / `AIStrategy_cap0.py`，两者都在 vs4 归档里）：

1. 常量 + 说明（第 102 行）；
2. `_own_shots_at(target_id)`：本机本局对该目标已发射次数（用帧序排除跨局残留）；
3. `_is_launch_window()` 开头加一道门：本机对该目标已打过 `>= 2` 发就返回 False。

选这个插入点是因为主空战发射路径（4 处）全部经过 `_is_launch_window`，改动面最小。
`cap=0` 时整段逻辑短路，行为与未改前**完全一致**，所以这是干净的单开关对比。

**为什么是"单机"上限而不是"编队"上限**：先量过才能定。09-14 那批里
60.8% 的 plus 发射是"同一架飞机重复打自己打过的目标"（命中率 15.9%），
只有 3.8% 是"打队友打过的目标"（命中率 2.3%）。所以单机上限就能覆盖绝大部分浪费，
不必动编队通信（那要改数据包序列化，风险大得多）。

## 结果

### 比分

| 批次 | 对照（cap=0） | 处理（cap=2） | 差 |
|:---|:---|:---|:---|
| plus 红 / 原版 蓝 | 59 : 41 | **80 : 20** | +21 |
| plus 蓝 / 原版 红 | 99 : 1 | 90 : 10 | −9 |
| **合计** | 158 : 42（79.0%） | **170 : 30（85.0%）** | **+12** |

### 发射效率（ACMI 严格同帧口径）

| 指标 | 对照 | 处理 | 差 |
|:---|---:|---:|---:|
| plus 发射 | 1150 | **963** | −187（−16.3%） |
| plus 命中 | 300 | **335** | **+35（+11.7%）** |
| plus 命中率 | 26.1% | **34.8%** | **+8.7pp** |
| ├ 长机(1/3) | 404 / 103（25.5%） | 356 / 125（35.1%） | |
| └ 僚机(2/4) | 746 / 197（26.4%） | 607 / 210（34.6%） | |
| 原版发射 | 476 | 378 | −98 |
| 原版命中率 | 34.5% | 38.9% | +4.4pp |

**关键：少打 187 发，反而多中 35 发。** 不是打得准了，是把几乎不中的弹删掉了。

### 机制验证（ACMI x ACAS_04 日志联合）

同一架飞机、同一目标的第 N 发：

| 第 N 发 | 对照 09-14 | 命中率 | 处理 09-16 | 命中率 |
|---:|---:|---:|---:|---:|
| #1 | 448 | 43.5% | 521 | 40.9% |
| #2 | 363 | 28.4% | 442 | 27.6% |
| **#3** | 205 | 2.9% | **0** | — |
| **#4+** | 124 | 0.8% | **0** | — |

**#3/#4 精确归零**，且单发质量基本没变（#1 43.5%→40.9%，#2 28.4%→27.6%）。
命中率的提升 **100% 来自删掉了零收益补射**，不是单发变准。
"重复打同一目标"的占比从 60.7% 降到 45.9%（硬上限 2 时限值约 50%，已接近天花板）。

## 怎么解读

- **效率结论（强）**：发射 −16%、命中 +12%、命中率 +8.7pp，都远超噪声
  （命中率的批间 SD 只有 0.47pp）。这一条可以定论。
- **比分结论（中）**：+6pp 落在单批噪声带（±5~7pp）边缘，方向有利但单次不足以定论；
  不过它和效率结论、机制验证三者自洽。
- **未解释的部分**：红方 +21、蓝方 −9，严重不对称。蓝方效率几乎没动
  （34.0%→34.8%），但胜率掉了 9 场。这个需要再看，别当成噪声一笔带过。

## 建议

1. **保留这个开关并设为 2**（`REATTACK_MAX_SHOTS_PER_TARGET = 2`），它是目前唯一
   有强证据的改动。
2. **补一轮验证**：处理组再跑 1~2 批（约 8 分钟/批），把比分证据从 1 个样本提到 2~3 个。
3. **查蓝方那 9 场**：优先用 `vs4_throttle_plus_blue_20260916_143613` 的 0010、0040、0064
   这几场（原版突防/plus 失分）在 Tacview 里回看。
4. 可选：试 `cap=3` 看是否比 2 更好（#3 命中率 2.9%，理论上 3 仍略亏）。
