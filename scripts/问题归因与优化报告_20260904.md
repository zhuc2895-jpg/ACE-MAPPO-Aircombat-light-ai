# 龙智杯问题归因与优化报告

## 结论

2026-08-29 的 20 场评测均完成，Python DLL 初始化成功且 `stderr` 为空。因此主问题不是平台完全无法运行，而是提交包存在环境隐含假设，并叠加策略接口和战术逻辑问题。

归因优先级：

1. **环境/提交包**：Python 路径硬编码、`Result/` 和 `AcmiRecord/` 缺失、`torch` 与嵌入式 Python/DLL 版本不一致。
2. **接口/策略**：`flightRole` 为 FREE 时必须稳定兜底；发射使用 `shootFlag`，并按 `AcasRdrGuideNum` 限制并发制导。
3. **策略逻辑**：预测预警机位置只能用于搜索，不能直接进入火控猎杀分支。
4. **评测设计**：红方先手/出生位置造成自对抗 100:0，不能单独证明策略泛化能力。

## 已实施优化

- `_can_fire_missile()` 默认允许最多 8 个并发制导源，并读取配置 `AcasRdrGuideNum`。
- 预测目标标记为 `is_predicted_target`，禁止进入预警机猎杀和发射安全判定。
- 新增 `环境自检.py`，检查 Python 3.8、依赖、输出目录、UDP 端口和 Python 路径。

## C++ 工程必须同步修改

`PyAIWrapper.cpp` 当前仍硬编码 `C:\Users\iop\AppData\Local\Programs\Python\Python38`。应改为优先读取环境变量 `LONGZHI_PYTHON_HOME`，未设置时回退到手册规定的 `D:\anaconda\envs\mappo`，并重新编译 4 个 DLL。
